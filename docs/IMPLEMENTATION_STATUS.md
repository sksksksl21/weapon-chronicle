## 코드 소유 경계에서 확인한 중요 사실

- 실제 전투는 game_runtime.js의 COMBAT_DOC_B64를 해독해 iframe srcdoc으로 실행한다. 이 해독 결과는 Git blob `2c19273d555cab4fbb8c97b1d4023a9ea9db4fe6`이며 추적 파일 combat_story.html과 정확히 같다. 따라서 단순 미사용 파일이라 삭제할 대상이 아니라, 전투 원본과 매립본을 함께 관리해야 하는 중복 원천 위험이다. 다음 전투 PR은 둘을 동일하게 갱신·검증해야 한다.
- render, loadGame, genMonth 등의 이전 정의가 파일에 남아 있어도 뒤의 래퍼/대입이 실제 동작을 결정한다. 예전 자발 계승 함수나 공명 방문 문자열을 발견한 것만으로 활성 기능이라고 보고하지 않았다.
- UI 폭 검사 통과는 모바일 UX 전체 완료가 아니다. 이번에는 버튼 크기, 텍스트 가독성, 타격 중 위치 변화, 실제 장비 교환, 모든 거래를 보증하지 않는다.

**거절:** 지금 프레임워크 교체·전면 재작성·대규모 콘텐츠 추가·최종 아트 일괄 재생성. 결함과 규칙 차이를 감춘 채 v5.5부터 구현하는 순서도 채택하지 않는다.
